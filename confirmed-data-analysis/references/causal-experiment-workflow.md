# 实验与因果推断工作流

## 方法路由

先判断数据生成机制，再选方法：

| 场景 | 能力 | 可回答的问题 |
|---|---|---|
| 已随机分流 | `experiment_analysis` | ITT 为主的实验效应与显著性 |
| 实验尚未开始 | `experiment_sample_size` | 给定基线、MDE、alpha 和 power 的样本量 |
| 非随机、个体级处理 | `propensity_score_matching` | 在可观测混杂可控制假设下的 ATT/ATE/ATC |
| 单个或少量地区、市场、产品受干预 | `synthetic_control` | 相对加权供体组合的干预后差异 |

用户说“分析实验”不代表一定随机。无法确认随机分流时，先询问分流机制，不得自动选择显著性检验或 PSM。

## 统一口径门

确认表必须展示：

- 业务假设、主指标、护栏指标及每个指标的分子、分母、去重键、单位和方向
- 处理组、对照组、分流或干预时间、分析单位、纳入排除规则、观察窗口
- estimand、alpha、power 或置信水平、单双侧、MDE 及其绝对/相对尺度
- 异常值、缺失值、多重检验、聚类、重复观测和方差缩减策略
- 方法专属识别假设与失败阈值

“指标名称相同”不代表口径相同。比率指标必须确认分子分母聚合方式；用户级随机实验不得直接把事件行当独立样本。

## 随机实验

默认主结论使用 ITT。先输出样本流和 SRM，再输出实验效应。

执行顺序：

1. 检查实验 ID、互斥性、重复分流、首个分流版本、时间边界和污染。
2. 按已确认的分流单位聚合；实际曝光分析只能作为补充，除非 estimand 明确不是 ITT。
3. 做 SRM 检查。SRM 失败且策略为 `block_inference` 时停止显著性结论。
4. 二元指标报告组均值、绝对差、相对 uplift、置信区间和两比例检验；连续指标报告均值差、标准化效应和 Welch 或聚类稳健检验。
5. 比率、重尾或重复观测指标使用 delta method、bootstrap、线性化或聚类稳健方法，并说明选择。
6. 主指标先报告 effect size 和置信区间，再报告原始及多重校正后的 p 值。
7. 同时判断统计显著性、方向、MDE/业务阈值和护栏风险。不得用 `p > alpha` 表述“没有效果”。

## 样本量

二元指标至少需要基线率和 MDE；连续指标至少需要标准差和 MDE。必须确认 MDE 是绝对、相对还是标准化效应。

计算时纳入分配比例、单双侧、多组校正、聚类设计效应和流失率。输出对照组、单个处理组、总样本量、膨胀后样本量和基于日流量的预计时长，并给出至少三个 MDE 或基线情景的敏感性表。

不得把历史观测流量当作保证到达的流量。若基线或标准差来自很小样本，标记样本量结果不稳定。

## PSM

PSM 只平衡已观测混杂，不能修复未观测混杂、反向因果或错误时间顺序。

执行顺序：

1. 定义共同索引时间、处理、结果窗口和 estimand。
2. 只使用处理前协变量。任何处理后变量、结果代理或受处理影响的变量都要移除或重定义时间。
3. 拟合 propensity score，并报告模型与随机种子。
4. 检查共同支持和 positivity；记录被裁剪及无法匹配的样本。
5. 匹配后逐变量报告标准化均差，默认以 `|SMD| < 0.1` 作为建议阈值，但以已确认契约为准。
6. 平衡或重叠不合格时，不输出强因果结论；不要仅为追求显著性反复调参。
7. 报告 ATT/ATE/ATC、置信区间、方差方法和未观测混杂敏感性分析。

## 合成控制

要求单位 × 时间的平衡面板，处理单位在干预前有足够长历史，供体同期未受同一干预或溢出影响。

执行顺序：

1. 检查面板完整性、干预时间、提前反应、供体污染和结构性断点。
2. 仅用干预前数据选择权重与超参数，报告非零供体权重。
3. 报告干预前 RMSPE/MAE/MAPE；预拟合超过阈值时阻止效应宣称。
4. 输出观察值、合成值、逐期 gap 和干预后平均效应。
5. 做空间安慰剂或时间安慰剂，使用排名或经验 p 值描述稀有程度。
6. 用 leave-one-donor-out、不同预窗口和供体池做稳健性检验。

## 输出结论等级

- `validated`: 设计、口径、诊断和统计检验均通过，可按对应 estimand 解释。
- `directional`: 方向可描述，但样本量、诊断或稳健性不足。
- `identification_failed`: SRM、平衡、重叠、预拟合或污染检查失败，不得宣称因果。
- `incomparable`: 指标、窗口或人群口径无法对齐。

所有方法都必须同时输出反证、限制和下一步验证，不得只展示显著结果。
